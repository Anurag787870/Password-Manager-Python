# 🔐 Password Manager (Python)

A menu-driven Password Manager built with Python that allows users to securely manage account credentials using JSON file storage.

## ✨ Features

- ➕ Add New Account
- 👀 View All Accounts
- 🔍 Search Account
- 🔄 Update Password
- 🗑️ Delete Account
- 🔑 Generate Random Strong Password
- 💾 Store Data in JSON File

## 🛠️ Technologies Used

- Python
- JSON
- File Handling
- Random Module
- String Module
- Functions
- CRUD Operations

## 📂 Project Structure

```
Password-Manager/

```

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python password_manager.py
```
